# Spaced Repetition

## How I run it
Anki deck "CS-core", 25 new cards/day cap, review cutoff 400 cards.
Leitner boxes on paper for non-tech material.

## Effectiveness
Retention of the DBMS syllabus hit 92% in mock tests using the schedule
below. Cards created same-day beat next-day cards by roughly 15%.

## Intervals (Leitner)
Box 1: 1 day — Box 2: 3 days — Box 3: 7 days — Box 4: 21 days — Box 5: 60 days
Wrong answer drops two boxes, never below Box 1. Feeds the Hindi flashcards
idea in [[project-ideas]].
